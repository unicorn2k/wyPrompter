# 无忧提词器（WyPrompter）设计文档

> 版本：1.0.0 ｜ 应用 ID：`com.wyprompter` ｜ 语言：Kotlin ｜ UI：Jetpack Compose (Material 3)
> 最低系统：Android 7.0（API 26） ｜ 目标系统：Android 15（API 35）

---

## 1. 项目概述

**无忧提词器**是一款 Android 手机端提词（teleprompter）应用，面向口播、直播、演讲等场景：

- 支持在**悬浮窗**中跨应用提词（录制/直播时不跳转界面）；
- 也支持**应用内全屏**提词，并可通过蓝牙遥控器翻屏、暂停/继续；
- 提词滚动采用"整稿无缝滚动"（teleprompter 风格），可调节字体、速度、透明度、颜色、背景与窗口大小；
- 支持从 `.txt` / `.docx` 导入文稿，稿件本地保存在 Room 数据库。

**设计原则**

1. 内容优先：提词正文始终不被按钮遮挡（悬浮窗正文区穿透、应用内固定控制栏夹持布局）。
2. 两种模式统一引擎：悬浮窗与应用内共用同一套 `AutoScrollEngine` 滚动模型。
3. 纯函数可测：按键映射、滚动数学、分段逻辑抽离为无 Android 依赖的纯 Kotlin 对象。
4. 无网络、无统计：数据不出设备，符合隐私政策承诺。

## 4. 核心功能模块设计

### 4.1 稿件数据层（data）

**实体** `Manuscript`（表 `manuscripts`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long | 主键，自增（0 = 未保存的新稿） |
| `title` | String | 标题 |
| `content` | String | 提词正文 |
| `createdAt` / `updatedAt` | Long | 创建/更新时间 |

**DAO** `ManuscriptDao`：

- `observeAll()` → `Flow<List<Manuscript>>`，按 `updatedAt DESC` 排序，供 UI 实时刷新；
- `getById(id)` / `insert`（冲突策略 REPLACE，返回新 id）/ `update`（整体覆盖 + 刷新时间戳）/ `delete`。

**设置仓库** `SettingsRepository`（SharedPreferences `settings`）：字体、速度、透明度、字体颜色、自动滚动、背景颜色、悬浮窗大小预设与自定义坐标、当前稿件 id、是否悬浮窗模式等（详见 §7）。

> 悬浮窗服务读取稿件正文走同步阻塞路径：`runBlocking { dao.getById(...) }`——仅针对单篇小文本，可接受。

### 4.2 编辑页与导入（ui/HomeScreen → EditorPane）

- 标题 `OutlinedTextField` + 内容 `OutlinedTextField`（提示"空行分段"）；内容区域高 190dp。
- 三个按钮：**导入文件 / 保存 / 开始提词**。
- 导入：`ActivityResultContracts.OpenDocument()`，按扩展名分发：
  - `.docx` → `TextImporter.fromDocx`（POI 解析段落与表格文本）；
  - `.doc` → 提示"请另存为 .docx"；
  - 其他 → `fromTxt`（UTF-8 解码）。
  - 导入结果直接写入编辑草稿（`viewModel.editingContent`）。
- 保存 / 开始提词前都会调 `viewModel.save(...)`：`id==0` 走插入，否则 `getById` 后 `copy` 更新；`onSaved(newId)` 回写 `editingId` 并 `setCurrent`。
- 更新"开始提词"先保存再按模式启动（见 §4.5）。

### 4.3 滚动引擎（scroll）

**模型（ScrollMath，纯函数）**

- `maxScrollOffset = max(0, 内容高 − 视口高)`；
- `durationMs = (剩余高度 / 速度px每秒) × 1000`；
- `progress = 当前偏移 / 最大偏移`（钳制 0..1）。

**引擎（AutoScrollEngine）**

- 由 `ValueAnimator` + `LinearInterpolator` 匀速驱动 `ScrollView.scrollY` 从当前位到 `maxOffset`，线性即"匀速滚屏"；
- 从当前视口位置续滚（暂停/调速后不跳回顶部）；已在底部时重置回顶部重滚；
- 布局未完成（高度为 0）时最多重试 20 次 layout pass，避免 addView 后静默失败；
- 回调：`onProgress(0..1)`（用于百分比指示）、`onScrollEnd`；
- `stop(reportEnd)` 保留现场；`reset/release` 回退到顶部。

**分段（ParagraphSplitter）**：按"一个或多个空行"或分隔行切分段落（当前滚动为整稿连续滚动，分段函数保留供扩展逐段翻页）。

### 4.4 悬浮窗模式（overlay）

`TeleprompterOverlayService` 为前台服务（`foregroundServiceType="specialUse"`），承载两个独立窗口：

| 窗口 | LayoutParams 标志 | 作用 |
| --- | --- | --- |
| 内容窗 `overlay_content` | `NOT_FOCUSABLE \| NOT_TOUCH_MODAL \| NOT_TOUCHABLE` | 滚动正文完全**穿透触摸**，下层录制/直播控件不受影响 |
| 控制条窗 `overlay_control_bar` | `NOT_FOCUSABLE \| NOT_TOUCH_MODAL` | 接收触摸，底部贴齐内容窗下沿 |

**控制条按钮**：上一屏 / 减速 / 播放暂停 / 加速 / 下一屏 / 字号 − / 字号 + / 拖动 / 缩放 / 关闭。

- **拖动**：按住"拖动"按钮移动 → 两窗同步位移，松手持久化 `overlayX/Y`；
- **缩放**：按住"缩放"按钮拖动 → 内容窗等比改宽高（180dp×120dp 下限），持久化宽高并切到 `overlayPresetSize=-1`；单击则循环 1/3 → 1/2 → 2/3 屏预设；
- **字号/速度**：实时写入设置并触发引擎重算（`engine.start()` 从当前位置按新速度续滚）；
- **播放/暂停**：维护 `autoScrollRequested` 状态（而非仅依赖 animator），同步切换播放图标。

内容窗布局（`overlay_content.xml`）：`ScrollView`（上下留边，隐藏滚动条）+ 单一 `TextView`（整稿内容），角标 `TextView` 实时显示百分比。

### 4.5 应用内模式（ui/InAppPrompter）

- 非悬浮窗时 `MainActivity` 用 `showInAppPrompter` 状态切换到 `InAppPrompterScreen`，内容标题 + 正文传入；
- 布局为**上下夹持**：顶部返回栏（含标题）+ 中间提词框（`weight(1f)` 全宽，`clipToBounds()`）+ 底部控制栏；上下栏均加不透明背景，提词框内顶部留 10dp 内边距，杜绝文本与返回按钮重叠；
- 控制：**上一屏 / 暂停·继续 / 下一屏 / 减速 / 加速** + 进度百分比；
- 翻页按**行对齐**：`snapToLine(target, max)` 把目标位置对齐到 `textView.lineHeight` 的整数倍，翻页后顶部永远是一整行而非半行；
- 复用 `AutoScrollEngine`；控制器 `InAppPrompterController` 以**单例** `instance` 暴露，供 `MainActivity` 的按键/触摸事件直接调用 `next()/previous()/toggle()`（见 §4.6）；
- 进入时 `controller = ctrl` 并写入 `instances`，退出时 `release()` 置空。

### 4.6 蓝牙遥控（remote + MainActivity）

**通用键码映射（RemoteKeyController，纯函数含单测）**

- NEXT：音量+、媒体下一首、快进、DPAD 下/右、PGDN、相机、对焦、PROFILE_SWITCH(188) 等；
- PREV：音量−、上一首、快退、DPAD 上/左、PGUP 等；
- TOGGLE：播放/暂停、播放、暂停、DPAD 中心、空格、回车等；
- 另含音量变化轮询（100ms 对比 `STREAM_MUSIC` 级）适配无键码上报的设备。

**LY-03 特殊方案（关键设计）**

实测 LY-03 以蓝牙 HID 枚举为"Consumer Control + Touchscreen"两个虚拟设备，三个实体按键上报的 `keyCode` 恒为 188、`scancode` 恒为 256，**无法用键码区分**。其真实差异呈现在内核触控轴的 `ABS_Y` 位置，最终由系统合成 **devId = -1 的 Virtual 触摸事件**：

| 按键 | Virtual 触摸 ACTION_DOWN 的 y 占比（fraction） |
| --- | --- |
| "+"（下一屏） | ≈ 0.350 |
| " − "（上一屏） | ≈ 0.620 |
| 电源（暂停/继续） | ≈ 0.400 |

判定规则（`MainActivity.classifyLyKey`）：

- 仅在 `deviceId == -1 && showInAppPrompter` 时处理；
- 用 `ACTION_DOWN` 的 `y / 屏幕像素高度` 计算 fraction，容差 **±0.035** 三带归类；
- 命中后消耗整条指针事件（直到 UP/CANCEL，`virtualPointerConsuming` 记录 pointerId），避免 Compose 收到"幽灵点击"；
- `ACTION_UP` 的 y 是被动画化的终点值（不确定性），**不使用**；
- `dispatchKeyEvent` 中拦截条件为设备名**不含 "LY-03"**（1024 键码路径对 LY-03 放行），防止一条按键双重触发。

> 局限：该方案强依赖遥控器把三键放在屏幕不同纵向位置；悬浮窗模式不处理遥控（提示文案已注明）。

### 4.7 设置与权限（ui/HomeScreen → SettingsPane）

设置 Tab 提供一行一个入口的卡片式引导：

- **蓝牙遥控器** → `ACTION_BLUETOOTH_SETTINGS`；
- **显示在其他应用上层** → `Settings.ACTION_MANAGE_OVERLAY_PERMISSION`（返回值触发 `maybeStartOverlay`）；
- **电池白名单** → `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`，并按厂商（华为/小米/OPPO/vivo…）给出 OEM 手动路径文案；
- **通知权限** → SDK≥33 时经 Activity 级 `registerForActivityResult` 申请 `POST_NOTIFICATIONS`（字段级注册，避免运行时注册崩溃）；
- **应用详情** → `ACTION_APPLICATION_DETAILS_SETTINGS`。

### 4.8 说明页与隐私政策（ui/HelpScreen）

- 第 4 个 Tab「说明」：顶部品牌渐变 Hero + 5 张功能卡片（快速开始 / 两种提词模式 / 蓝牙遥控 / 显示设置 / 稿件管理），每张卡含圆角图标徽章、彩色副标题、对勾要点；
- 底部"隐私政策"入口弹出 `PrivacyDialog`：圆角 24dp、圆形 `PrivacyTip` 徽章、版本副标题；内容按 5 节（数据存储 / 权限说明 / 网络与广告 / 权限撤销 / 政策变更）结构化渲染，超高时内部滚动，确认按钮关闭。

## 5. 关键算法与常量

1. **速度换算**：用户速度档 0.1..5（无量纲）→ 实际滚动 `speed × SPEED_SCALE(80f)` px/s。悬浮窗与 `InAppPrompter` 均落实该换算，保证两模式手感一致；应用内"减速/加速"按钮按 `/SPEED_SCALE` 还原档位、±0.2 步进写回。
2. **翻页行对齐**：`snapToLine(target, max) = clamp((target / lineHeight) × lineHeight, 0, max)`。
3. **遥控三带分类**：见 §4.6 表格，容差 0.035。
4. **悬浮窗双窗口几何**：控制条 Y = 内容窗 Y + 内容窗高 − 控制条高；拖动/缩放/预设切换处均维护该约束。
5. **布局就绪重试**：滚动启动前高度为 0 时 `post` 重试最多 20 次。

## 6. 关键状态与数据流

- **文本输入草稿**：`PrompterViewModel.editingId/ editingTitle / editingContent`（普通 `mutableStateOf`，随 Composable 重组而存活，区别于仅依赖 `remember` 的 HomeScreen 内部状态）——保证切屏/提词返回后内容不丢。
- **稿件列表**：`manuscripts: Flow` → `collectAsState(initial=emptyList())`，DAO 更新即时反应。
- **设置状态**：VM 内 `mutableStateOf` 镜像 + 每次变更同步写入 SharedPreferences；`MainActivity`/悬浮窗服务直接读 Repository。
- **提词会话**：应用内 = `InAppPrompterController.instance` 单例；悬浮窗 = service 内 `OverlayContentController + AutoScrollEngine` 实例。
- **活动路由**：`startPrompter(title, content)` 依据 `settings.floatingWindow` 分流到悬浮窗（先查悬浮窗权限）或应用内。

## 13. 已知局限与后续规划（FAQ）

1. **LY-03 遥���依赖按键纵向位置**：改换遥控器可能失配，需在说明页引导"尽量把三键放屏幕不同纵向位置"（已内置文案）。

5. **滚动方向设置 `scroll_up` 为预留键**：当前未接入 UI。
