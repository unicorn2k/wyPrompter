# 提词器开发计划

> 项目：Android 提词器 App（wyPrompter）
> 文档用途：整体规划与开发执行计划

---

## 一、项目背景与目标

开发一款 Android 提词器 App，用于录像/直播时在屏幕上悬浮显示提词内容。核心需求：

1. **悬浮在其它应用之上**——可一边录像一边显示提词
2. **字体可调节**
3. **自动滚动**
4. **支持蓝牙遥控器远程上下翻页**

## 二、技术选型（已确认）

| 项目 | 选择 |
|------|------|
| 语言 | Kotlin |
| 架构 | 单模块，MVVM（ViewModel + Repository） |
| UI 混合 | 主界面用 **Jetpack Compose**；悬浮窗用 **XML View**（稳定性与性能） |
| minSdk | 26（`TYPE_APPLICATION_OVERLAY`） |
| 内容来源 | 手动粘贴/输入 + TXT/Word 导入 |
| 蓝牙遥控 | 自拍杆式蓝牙快门，监听音量键/媒体键/翻页键 |
| 翻页语义 | 换一段话（段落级翻页） |
| 目标设备 | 无特定机型/版本，做通用兼容（蓝牙协议需灵活适配） |

├── scroll/
│   ├── AutoScrollEngine        # 段落滚动引擎（ValueAnimator）
│   └── ParagraphSplitter       # 按段落切分提词稿
├── remote/

## 四、关键实现要点

### 1. 段落翻页 + 自动滚动逻辑
- `ParagraphSplitter` 用空行/分段符号把整稿切成段
- 当前「页」= 一段文本；滚动引擎只滚动该段
- **自动滚动**：`ValueAnimator` 从段首滚到段尾自动停止
- **遥控器动作**：`下一页` → 切到下一段并重新滚动；`上一页` → 切回上一段
- 手动模式：手动逐段切，或滚到段尾自动停

### 2. 蓝牙遥控（兼容无特定机型）
做成**三套监听并行 + 可配置映射**，覆盖大多数自拍杆：
- 媒体键（`KEYCODE_MEDIA_PLAY_PAUSE` 等）→ 通过 `MediaSessionCompat`
- 音量键（`KEYCODE_VOLUME_UP/DOWN`）→ 定向监听，可静音拦截
- 部分自拍杆发通用蓝牙键盘箭头键
- `KeyMappingConfig` 让用户在设置中把「音量+ / 播放 / 上箭头」等映射为「下一页/上一页」
- 先做按键捕获 Demo，打印实际按键码，据此配置默认映射

### 3. 悬浮窗细节
- 透明区可「点击穿透」（`FLAG_NOT_TOUCHABLE`）+ 保留可拖动的控制条，避免挡住录像操作
- 内容半透明可调，减少遮挡画面
- 位置/尺寸记忆
- `TYPE_APPLICATION_OVERLAY`（API 26+）+ `SYSTEM_ALERT_WINDOW` 权限

### 4. 权限与保活
- 悬浮窗：`SYSTEM_ALERT_WINDOW` + 引导跳转系统设置页
- 前台服务 + 常驻通知
- `BatteryOptimizationHelper`：引导用户将 App 加入电池白名单（通用步骤 + 品牌识别跳转）

### 5. 内容导入
- **TXT**：直接读取，支持指定编码（UTF-8/GBK 等，避免中文乱码）
- **Word**：Apache POI 解析 `.docx`，提取段落文本

## 五、开发阶段划分

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| **P0 骨架** | 项目初始化、依赖、权限引导、Compose 主界面壳 | 可运行空壳 |
| **P1 蓝牙验证** | 按键捕获 Demo，确认实际按键码 | 按键日志工具 |
| **P2 悬浮窗** | 悬浮窗显示、拖拽、字体、半透明、穿透 | 可用悬浮提词 |
| **P3 滚动+翻页** | 自动滚动引擎 + 段落切分 + 翻页交互 | 核心功能闭环 |
| **P4 蓝牙集成** | 按键映射 + 翻页绑定 + 保活引导 | 遥控可用 |
| **P5 内容与打磨** | 导入、多稿、设置记忆、适配 | MVP 完成 |

## 六、验证与适配要求

- **必须真机测试**：悬浮窗与蓝牙均无法在模拟器完整验证
- Phase 1 需提供手头自拍杆实际按键码，用于配置默认映射
- 需至少一部实际 Android 设备（手机/平板不限型号）
- 各品牌机型悬浮窗/电池白名单权限路径存在差异，需在引导页做品牌识别适配
